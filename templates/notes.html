UNDERSTAND THE WHY

Your Python field notes.

A small toolkit for turning raw text into something useful.

01 / STRINGS

Clean, then split.

strip() removes whitespace at the edges. split('|') separates a line into parts. Neither changes the original string.

'  CPU? | Processor  '.strip()
# 'CPU? | Processor'
'CPU? | Processor'.split('|')
# ['CPU? ', ' Processor']

Clean each part too. Validate that there are exactly two nonempty parts before building a card.

02 / DATA FLOW

Know the shape.

A line is a string. Splitting gives a list. A valid card is a dictionary with front and back keys.

line → parts → valid card → deck
str    list    dict         list

Invalid lines return None. They should never become empty cards in your deck.

03 / FILES

Open with care.

A context manager closes a file even if an error happens. Use UTF-8 so accented letters can be read correctly.

with open(path, encoding='utf-8') as source:
    for line in source:
        print(line.strip())

An empty file is valid and produces an empty deck. A missing file is a different problem.

04 / TESTING

Think beyond the happy path.

Test missing delimiters, extra delimiters, empty answers, and whitespace. A test is a small, repeatable claim about behavior.

' Q | A ' → valid
'Q'       → invalid
'Q|A|B'   → invalid
'Q| '     → invalid
